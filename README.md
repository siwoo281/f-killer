# 🛡️ F-Killer (배재대 출석 계산기)

> **"F학점, 확실하게 잡아드립니다."**  
> 배재대학교 학사 규정(시행세칙)을 완벽하게 반영한 **모바일 최적화 출석 계산기**입니다.

## 🚀 핵심 기능 (Key Features)

### 1. 🎯 칼같이 정확한 F학점 판독
- **1/3 초과 룰 적용**: 총 수업 시간의 1/3을 '초과'해야 F가 되는 규정을 정밀하게 구현했습니다.
- **"75분 수업" 자동 환산**: 학생들이 가장 헷갈려 하는 '3학점 주 2회 = 1.5시수' 계산을 자동으로 처리합니다.

### 2. ⚠️ '벼랑 끝' 정밀 경고 시스템
- **안전(Safe)**: "앞으로 몇 번 더 빠져도 되는지" 정확한 횟수를 알려줍니다.
- **위험(Warning)**: "단 한 번의 지각도 허용되지 않는" 턱걸이 상태를 감지하여 강력하게 경고합니다.
- **F확정(Danger)**: 이미 구제 불가능한 상태일 경우, 명확하게 시험 응시 불가 및 재수강을 안내합니다.

### 3. 🧮 지각/조퇴 자동 변환
- **"3회 = 1회 결석"**: 지각이나 조퇴 횟수를 입력하면 자동으로 결석 시수에 합산(Math.floor)하여 계산합니다.

### 4. 📋 공결 규정 가이드 내장
- 부모님 상, 예비군 훈련 등 **공결 인정 사유와 기간**을 앱 내에서 바로 확인할 수 있습니다.
- 인정되지 않는 사유(단순 감기, MT 등)도 명시하여 혼란을 줄였습니다.

### 5. 📱 모바일 최적화 (Mobile First)
- 별도 설치 없이 링크만으로 즉시 사용 가능합니다.
- 스마트폰 화면에 꽉 차는 디자인과 터치 친화적인 UI를 제공합니다.

## 🛡️ 면책 조항
본 서비스는 배재대학교 학칙 시행세칙을 기준으로 제작되었으나, 실제 전자출석부 반영 현황은 차이가 있을 수 있습니다. 결정적인 순간에는 반드시 **'헤이영'** 또는 **'통합정보시스템'**을 크로스 체크하시기 바랍니다.

## 💻 Tech Stack
- **HTML5 / CSS3 / Vanilla JavaScript**
- No Server, No DB (Client-side Only for Privacy)
